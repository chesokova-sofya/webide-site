Visual Studio Code (VS Code) — бесплатный редактор кода с открытым исходным кодом. Формально это редактор, а не полноценная IDE, но благодаря расширениям он подходит почти для любого языка. Для веб-разработки VS Code сразу поддерживает HTML, CSS, JavaScript и TypeScript: подсветку синтаксиса, автодополнение, Emmet, отладку и встроенный терминал.

Возможности

  • IntelliSense — автодополнение кода.
  • Emmet — быстрая вёрстка HTML и CSS.
  • Встроенная работа с Git.
  • Отладчик для JavaScript и Node.js.
  • Магазин расширений: линтеры, темы, Live Server.

Плюсы и минусы

Плюсы

  • Бесплатный
  • Быстро запускается
  • Большое сообщество

Минусы

  • Многое настраивается через расширения
  • Рефакторинг слабее, чем у JetBrains
