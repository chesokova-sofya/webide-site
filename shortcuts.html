Горячие клавиши

Самые полезные сочетания клавиш для Windows и Linux.

В macOS вместо Ctrl используется Cmd. В PhpStorm и WebStorm сочетания одинаковые.

Основные сочетания клавиш
Действие VS Code PhpStorm / WebStorm
Поиск файлаCtrl + PCtrl + Shift + N
Палитра команд / поиск вездеCtrl + Shift + PShift + Shift
ПереименоватьF2Shift + F6
Форматировать кодShift + Alt + FCtrl + Alt + L
Перейти к определениюF12Ctrl + B
Закомментировать строкуCtrl + /Ctrl + /
