Плагины и расширения

Расширения добавляют редактору новые возможности.

VS Code почти полностью строится из расширений, а в IDE JetBrains большинство инструментов уже встроено, но полезные плагины есть и для них.

Расширения для VS Code

  • Prettier

    Автоматическое форматирование кода.

  • ESLint

    Поиск ошибок в JavaScript.

  • Live Server

    Обновление страницы в браузере при сохранении.

  • GitLens

    История изменений каждой строки.

Плагины для PhpStorm и WebStorm

  • Laravel Idea

    Подсказки для фреймворка Laravel.

  • Tailwind CSS

    Автодополнение классов Tailwind.

  • Rainbow Brackets

    Цветные парные скобки.

  • .ignore

    Подсветка файлов .gitignore.
